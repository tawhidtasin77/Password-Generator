# Password Generator

A simple Password Generator built with React and Vite that creates random secure passwords based on user preferences.

## Features

- Generate random passwords instantly
- Adjust password length using a range slider
- Include numbers (0-9)
- Include special characters
- Copy password to clipboard with one click
- Dynamic password generation using React Hooks

## Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS

## React Hooks Used

- useState
- useEffect
- useCallback
- useRef

## How It Works

1. Select the password length.
2. Choose whether to include numbers.
3. Choose whether to include special characters.
4. A random password will be generated automatically.
5. Click the "Copy" button to copy the password.
